# Pridefetch 🌈

A customizable, LGBTQ+ themed system information
display built around Fastfetch.

## Features
- LGBTQ+ inspired themes
- First-run theme selection
- Saved theme preferences
- Real system information powered by Fastfetch

## Requirements
- Linux
- Bash
- Fastfetch

## Usage

Run Pridefetch:

    pridefetch

Change your theme:

    pridefetch --change-style
